# proiect-uptispoo
smec

Modelul OO porneste de la cele trei entitati: Car, Client, Rental
Pentru interactiunea cu interfata aplicatiei avem 3 interfete: cate una pentru fiecare model: ICar, IClient, IRental
clasele SERVICE implementeaza interfetele asociate

Tratarea erorilor se face cu ajutorul clasei Result
Folderul SEED contine clasa AppStateSeed cu ajutorul careia am populat aplicatia, pentru a contine date chiar de la prima rulare (am introdus masini, clienti si inchirieri)

Salvarea datelor se face prin intermediul folderului DATA si al celor trei clase pe care le cuprinde: AppController, AppStorage, JsonStorage
