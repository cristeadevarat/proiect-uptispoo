# Proiect UPTISPOO - Sistem Închirieri Mașini 🚗

Acest repository conține un proiect C# Windows Forms pentru managementul închirierilor de mașini.

### 🚀 Quick Start

```bash
# Clonare repository
git clone https://github.com/cristeadevarat/proiect-uptispoo.git

# Deschide solution în Visual Studio
cd proiect-uptispoo
start InchirieriMasini.sln

# SAU rulează din command line
dotnet build
dotnet run
```
